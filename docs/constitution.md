# Constitución — CSV Cleaner
Principios innegociables.

1. **Simplicidad primero**: HTML, CSS y JS puros. Sin build ni frameworks.
2. **Privacidad**: el archivo nunca sale del navegador del usuario.
3. **Integridad**: la limpieza nunca pierde ni altera datos que no deba tocar (comas, comillas, saltos de línea).
4. **Lógica separada de interfaz**: la limpieza son funciones puras, sin DOM.
5. **Tests como puerta**: la lógica se prueba con `node --test`; no se avanza con tests en rojo.
6. **Idioma**: código en inglés; interfaz en inglés; documentación en español.
